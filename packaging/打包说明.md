# 打包说明

使用 PyInstaller 6.16 的 one-folder 模式。选择 one-folder 而非 one-file，是为了提高 Tk、MediaInfo DLL、Pillow、imageio 和 pyJianYingDraft 数据文件的加载稳定性。

打包命令：

```text
.venv\Scripts\pyinstaller.exe --noconfirm --clean --distpath dist --workpath build packaging\assistant.spec
```

分发时必须发送完整的 `剪映高产剪辑助手` 文件夹，或发送生成的 ZIP；不能只发送文件夹内的 EXE。

也可以直接运行 `packaging\build_release.cmd`。推送 `v*` 标签后，GitHub Actions 会自动构建 Windows x64 ZIP 并发布到 Releases。
