# 剪映高产剪辑助手

[![Windows build](https://github.com/Tiroace/jianying-high-throughput-assistant/actions/workflows/windows-release.yml/badge.svg)](https://github.com/Tiroace/jianying-high-throughput-assistant/actions/workflows/windows-release.yml)

这不是另造一个视频编辑器。系统复用 `pyJianYingDraft` 生成可编辑的剪映草稿，把素材检索、镜头装配、字幕和多钩子/多结尾组合交给程序；剪映继续负责预览、精修和导出。

## 推荐入口：剪映悬浮插件

双击 `启动系统.cmd` 或 `剪映悬浮插件.cmd`。悬浮面板会检测剪映窗口并自动吸附在旁边；没有启动剪映时，也可以先在面板中编辑任务。

面板提供：

- 多钩子、多结尾直接粘贴，并实时计算批量草稿数。
- 正文按标点自动拆成镜头段落。
- 一键增量扫描素材库；未变化的素材直接复用缓存，大素材库无需反复读取视频信息。
- 一键批量生成剪映草稿，每次自动追加批次编号，不会与上一批重名。
- 直接打开素材库、草稿目录、启动剪映和完整工作台。

`完整工作台.cmd` 用于修改高级 JSON 任务与路径设置。

## 当前已经能做

- 扫描 `素材库` 中的视频、图片和音频，读取时长与画幅。
- 从文件名、文件夹名和 `.tags.txt` 边车文件建立素材标签。
- 根据文案段落的关键词自动匹配 B-roll。
- 按多钩子 × 多结尾生成多个可编辑剪映草稿。
- 自动建立主画面、字幕、配音和 BGM 轨道。
- 不覆盖已有同名草稿，生成后保留镜头选择报告。
- 检查剪映、草稿目录、FFmpeg 和草稿引擎状态。

## 使用方法

### 普通用户（无需安装开发环境）

在 GitHub 仓库右侧进入 **Releases**，下载 `剪映高产剪辑助手_Windows_x64.zip`。完整解压后双击 `剪映高产剪辑助手.exe`。不要只复制 EXE，也不要直接在压缩包中运行。最新发布页：<https://github.com/Tiroace/jianying-high-throughput-assistant/releases/latest>

系统要求：Windows 10/11 64 位、剪映专业版。无需安装 Python、Git、FFmpeg 或本项目依赖。

### 开发者

安装 Python 3.11 或 3.12 后运行 `安装环境.cmd`，再双击 `启动系统.cmd`。构建便携版可运行 `packaging/build_release.cmd`。

1. 把自有或已授权素材放入 `素材库`。推荐目录：`素材库/黄精/原料特写/xxx.mp4`。
2. 文件名尽量带镜头语义，例如 `黄精_原料_切片_特写_01.mp4`。
3. 双击 `启动系统.cmd`。
4. 在“快速生成”中直接粘贴钩子、正文和结尾；或者在“高级任务 JSON”中选择已有任务。
5. 点击“扫描素材库”，再点击“保存并生成剪映草稿”。
6. 重启剪映，或进出一次已有草稿，让剪映刷新本地草稿列表。
7. 在剪映中完成审片、微调和导出。

如果文件名不方便修改，可以在素材旁新建同名标签文件，例如：

```text
素材：A001.mp4
标签：A001.mp4.tags.txt
内容：黄精 原料 特写 切片 暖色 自有版权
```

## 文案任务结构

参考 `文案/示例任务.json`。系统会计算 `hooks × ctas`，并受 `max_variants` 限制，避免一次制造过多无意义版本。每个段落支持：

- `text`：字幕或口播文字。
- `duration`：目标时长，单位秒。
- `keywords`：用于素材匹配的关键词。
- `asset`：可选，强制指定某个素材路径。
- `role`：hook、evidence、usage、product、cta 等功能标签。

## 重要边界

- 当前剪映版本为 11.5。开源引擎能生成草稿，但剪映 7+ 已不能稳定使用旧式控件自动导出。
- 当前版本不操作鼠标、不注入剪映进程，也不修改剪映程序文件，因此比“外挂式 UI 点击器”稳定。
- 新版剪映的模板草稿可能不是明文 JSON，所以 v0.1 以“新建标准草稿”为主，不依赖读取用户复杂模板。
- AI 可以生成表达，不能伪造原料、检测、医生身份、用户疗效或工厂事实。
- 网络下载素材必须确认商业授权，系统不会用裁切、镜像等方式规避版权或搬运识别。

## 采用的成熟组件

- pyJianYingDraft 0.3.0：Apache-2.0，负责剪映草稿结构。
- MediaInfo（通过 pymediainfo）：读取本地素材元信息。
- 剪映专业版：人工审片、精修和导出。
- FFmpeg：已检测到本机现有版本，后续用于代理文件、音频处理和质检。

依赖通过 PyPI 安装；上游项目与许可证信息见 `THIRD_PARTY.md`。
